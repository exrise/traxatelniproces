# Свиновойна

Смесь **Forts** и **Worms**: сначала вы строите укрепления и расставляете юнитов-свиней за ограниченные деньги,
потом начинается пальба по очереди. Деньги зарабатываются прямо в бою и уходят на следующую стройку.
Играют **2–4 игрока** (по сети через Radmin VPN, за одним компьютером или против ботов).

* Один файл `SvinoVoyna.exe` — **никаких установок**: ни Python, ни .NET, ни Visual C++. Готовая сборка лежит в [`release/SvinoVoyna.exe`](release/SvinoVoyna.exe) (она же собирается в GitHub Actions). Windows SmartScreen может предупредить о неизвестном издателе — «Подробнее → Выполнить в любом случае».
* Вся графика и звук генерируются кодом (пиксель-арт). Свои картинки можно подложить в папку `assets/` (см. ниже).

## Как играть

Матч состоит из циклов **СТРОЙКА → БОЙ → СТРОЙКА → БОЙ …** пока не останется один игрок (или одна команда).
Проигрывает тот, чей **Штаб** разрушен.

### Стройка
Все строят одновременно (чужие базы скрыты). У каждого — зона на своём участке карты, лимит денег и таймер.
Слева панель покупок:

| Вкладка | Что внутри |
|---|---|
| Юниты | свиньи с разным оружием (штурмовик, дробовик, снайпер, гранатомётчик, миномётчик, оператор БПЛА, наводчик, инженер) |
| Оружие | пулемётное гнездо ДШК, гаубица Д-30, РСЗО «Град», ПТРК «Корнет», ПУ «Искандер», «Орешник» |
| ПВО | ЗУ-23-2, «Панцирь-С1», С-400, РЭБ |
| Защита | мешки с песком, бетон, бронеплита, ёж, бункер, антидроновая сетка |
| Экономика | нефтевышка, свиноферма (доход каждый твой ход) |
| Удары | авиаудары ФАБ-500, КАБ-1500 и дрон-камикадзе «Герань» (расходники, вызываются в бою из штаба) |

* **ЛКМ** — поставить, **ПКМ** — продать (возвращается часть цены), **R** — починить объект под курсором, «Починить всё» — починить всё сразу.
* Клик по своему юниту без выбранного предмета — переставить его.
* Постройки встают на землю или на другие постройки; без опоры они падают. Над штабом можно построить крышу — она ловит бомбы и снаряды сверху.
* Радиус ПВО показан голубым овалом: он вытянут вверх, ПВО достаёт и до самолётов.
* Часть оружия открывается только со 2-й стройки.

### Бой
Ходят по очереди (порядок сдвигается каждый раунд). Режим хода выбирается в лобби:

1. **Классика Worms** — за ход одно действие: выстрел юнита *или* орудия *или* вызов удара.
2. **Юнит + постройка** — за ход можно сделать и то, и другое (урон ×0.75).
3. **Одновременные ходы** — все планируют выстрел за 30 секунд, потом всё разыгрывается разом.

Управление в бою:

| Клавиша | Действие |
|---|---|
| `A` / `D`, стрелки | идти |
| `W`, `↑`, `Enter` | прыжок |
| мышь | прицел |
| **ЛКМ** / `Пробел` | огонь (для навесного оружия — **держи** для силы и отпусти) |
| `1`…`9` или клик по панели | выбрать оружие |
| `Tab` / `Q` | следующий юнит / следующее орудие |
| `E` | закончить ход |
| `T` | траектория вкл/выкл |
| ПКМ + перетаскивание, колесо | камера, масштаб |
| `Esc` | пауза |

Особенности оружия:

* **Миномёт, гаубица, граната, «Град»** — навесом; на них влияет ветер (стрелка слева вверху).
* **Искандер, «Орешник»** — выбери цель кликом по карте и нажми «Огонь!». Ракета летит сверху, стены её не останавливают; «Орешник» разваливается на 6 боевых блоков и почти не перехватывается.
* **Авиаудары** (ФАБ, КАБ) и **«Герань»** — выбираешь точку на карте. С живым **Наводчиком** точность намного выше.
* **FPV-дрон** управляется мышью: летит за курсором, клик/пробел — подрыв.
* **ПВО** стреляет автоматически по чужим самолётам, дронам и ракетам, пока есть боезапас; залп «Града» или толпа дронов может его перегрузить. РЭБ глушит дроны.

### Деньги в бою
* за нанесённый урон (юнитам — полностью, постройкам — меньше) и бонус за убийство;
* постройки-добытчики приносят доход каждый твой ход;
* **точки захвата** (флажки в середине карты): встань рядом юнитом и держи — доход идёт тебе;
* помощь отстающему: урон по лидеру оплачивается лучше (★ в списке игроков), а часть потерь возвращается на следующей стройке.

Если матч затянулся, с 4-го боя штабы начинают гореть («внезапная смерть», настраивается).

## Пресеты баланса и настройка

В лобби выбирается пресет: **Стандарт**, **Окопная война**, **Ракетный ад**, **Пехота**, **Блиц**.
Кнопка **«Тонкая настройка…»** открывает редактор *всех* чисел: цены, урон, радиусы, боезапас, ПВО, экономика, таймеры.
Свои пресеты сохраняются в папку `presets/` рядом с exe (обычные JSON-файлы) и появляются в списке.
Баланс хоста автоматически передаётся остальным игрокам по сети.

## Игра по сети через Radmin VPN

1. Все игроки ставят и запускают **Radmin VPN**, заходят в одну сеть (каждый получает адрес вида `26.x.x.x`).
2. **Хост**: «Создать сетевую игру». В окне будет написан его адрес (например `26.12.34.56:27015`) — его надо сообщить друзьям. Настройте места (человек / бот / закрыто), баланс и нажмите «СТАРТ».
3. **Остальные**: «Подключиться к игре», вписать IP хоста, нажать «Подключиться». Ждать старта.
4. Если Windows спросит про брандмауэр — **разрешите доступ** (частная сеть). Порт по умолчанию `27015/TCP`; если не получается, добавьте для `SvinoVoyna.exe` правило входящих подключений.

Хост ведёт симуляцию, остальные получают картинку и отправляют команды (трафик крошечный). Если кто-то отвалился во время игры — его место займёт бот.

## Свои картинки
Если положить PNG в `assets/`, игра подхватит их вместо сгенерированных. Имена файлов:
`s_<id постройки>.png` (например `s_d30.png`, размер `ширина*16 × высота*16`), `pig_<цвет 0-3>_<id юнита>_<кадр 0-3>.png` (24×24), `sky.png`, `mtn_far.png`, `mtn_mid.png`, `mtn_near.png`, `cloud0.png`.

## Сборка из исходников
Нужен только [Go 1.24+](https://go.dev/dl/). Python не нужен.

```
# Windows (cmd)
build.bat

# Linux/macOS: собрать exe для Windows
./build.sh
```

Готовый `dist/SvinoVoyna.exe` собирается также автоматически в GitHub Actions (артефакт `SvinoVoyna-windows`).

### Инструменты разработчика
* `go test ./internal/sim ./internal/balance ./internal/ai ./internal/netplay` — тесты логики без графики.
* `go run ./cmd/balancecheck -n 100 -players 3 -weapons` — турнир ботов: винрейты стратегий, влияние места на карте, длительность матча, эффективность каждого оружия.
  Ключи: `-preset "Ракетный ад"`, `-trace -seats 3,4` (подробный лог одного матча), `-static` (таблица по конфигу).

## Устройство проекта
```
cmd/svinovoyna      — запуск игры
cmd/balancecheck    — проверка баланса ботами
internal/sim        — вся игровая логика (без графики): ландшафт, юниты, стройка, оружие, ПВО, экономика, ходы
internal/balance    — конфиг баланса и пресеты
internal/ai         — боты (расчёт траекторий, закупки)
internal/netplay    — сеть: хост, клиент, снапшоты
internal/gfx        — процедурная пиксель-графика
internal/sfx        — синтез звуков
internal/ui         — сцены, интерфейс, отрисовка
```
