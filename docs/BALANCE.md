# Баланс «Свиновойны»

Все числа лежат в `internal/balance/presets.go` (пресет «Стандарт» — эталон) и редактируются в игре
(лобби → «Тонкая настройка…»). Этот документ объясняет, **почему** числа такие и как их проверять.

## Принципы

1. **Одно действие за ход.** В «Классике» игрок за ход делает один выстрел (юнит, орудие или удар). Значит, «число
   выстрелов за бой» ограничено раундами (6 на двоих, 5 на троих, 4 на четверых — чтобы бой не затягивался), а деньги
   покупают не *количество*, а *качество* действий: от дешёвого миномёта (~70 урона) до «Орешника» (~750).
2. **Боезапас вместо кулдауна.** Орудия на базе стреляют 1–5 раз за бой, юниты — без ограничений, но слабее.
   Поэтому пехота дёшево «заполняет» ходы, а орудия/удары — главная ударная сила.
3. **Каждому оружию — свой ответ:**
   * навесные снаряды (Д-30, миномёт) → стены и **крыши** (взрыв гасится блоками на пути);
   * ракеты «Град» → ПВО с запасом боезапаса (залп из 10 ракет перегружает ЗУ-23);
   * авиаудары и «Герань» → ПВО (ЗУ-23, «Панцирь», С-400), которое достаёт и до самолётов (радиус вытянут вверх);
   * «Искандер» и «Орешник» летят сверху мимо стен → только С-400 (60 % / 20 %) или запас прочности штаба;
   * FPV-дроны → РЭБ, антидроновая сетка, ЗУ-23;
   * юниты в открытом поле → ДШК, снайпер, дробовик.
4. **Антиснежный ком (важно при игре втроём и вчетвером).**
   * урон по самой богатой армии оплачивается ×1.3 (★ в списке), по самой слабой — ×0.7;
   * 25 % потерянной стоимости возвращается на следующей стройке (до 600 $);
   * лимиты: Искандер/С-400/Орешник — по одному на игрока и со 2-й стройки; Д-30 и «Град» — не более 3 и 2;
   * бои короче при большем числе игроков, а «внезапная смерть» (с 4-го боя штабы теряют HP каждый раунд, на 3–4 игрока
     — раньше и сильнее) гарантирует финал.
5. **Деньги в бою:** 1 $ за очко урона юнитам, 0.35 $ за очко урона постройкам, +80 $ за убийство, +10 % цены за
   разрушенную постройку, нефтевышка +60 $, ферма +35 $, точка захвата +100 $ за каждый свой ход.

## Как проверять

```
go run ./cmd/balancecheck -static                 # таблица по конфигу
go run ./cmd/balancecheck -n 100 -players 2 -weapons   # турнир ботов + эффективность оружия
go run ./cmd/balancecheck -matrix 8               # «каждый с каждым» 6 стратегий ботов
go run ./cmd/balancecheck -n 60 -players 3        # игра втроём: винрейты, длительность, влияние места
go run ./cmd/balancecheck -trace -seats 4,5       # лог одного матча по боям
```

Стратегии ботов: *Сбалансированный, Пехота, Турели, Ракеты, Черепаха, Авиация*.
Боты считают траектории с учётом ветра, строят крыши над штабом и покупают ПВО, поэтому цифры близки к
поведению аккуратного игрока (но люди сильнее: они адаптируются, строят ловушки, ходят юнитами).

## Результаты (пресет «Стандарт», боты, 50 минут на матч)

Матрица «каждый против каждого» (2 игрока, итоговый процент побед стратегии):

| Стратегия | Итого |
|---|---|
| Сбалансированный | ~46 % |
| Черепаха | ~50 % |
| Авиация | ~45 % |
| Пехота | ~35 % |
| Ракеты | ~31 % |
| Турели | ~30 % |

* Разброс 30–50 %: нет стратегии, которая выигрывает всё; есть «камень-ножницы-бумага» (авиация сильна против слабого ПВО,
  черепаха с ПВО ломает авиацию, ракеты и массовая артиллерия давят черепаху, пехота добивает расслабленных).
* Матч на двоих — в среднем 30–35 минут (5 боёв), на троих — ~35, на четверых — ~30 (за счёт сокращения раундов и внезапной смерти).
* Место на карте (случайное) и порядок первого хода (случайный) почти не влияют: победы по местам различаются в пределах шума.
* Втроём/вчетвером выигрывают разные стратегии, ни одна не берёт больше ~40 %.

Другие пресеты:

* **Окопная война** — стены дешевле и крепче, удары дороже, 8 раундов. Сильнее авиация и турели, медленная игра.
* **Ракетный ад** — много денег, всё оружие открыто с первой стройки, штаб слабее, внезапная смерть с 3-го боя. Для коротких яростных матчей.
* **Пехота** — юниты дешевле, нет «Орешника», больше юнитов.
* **Блиц** — мало денег и времени, 4 раунда. Здесь авиация чувствует себя лучше всего.

## Что крутить, если хочется другого

| Хочется… | Крутить |
|---|---|
| Короче/длиннее матч | «Раундов в бою», прочность штаба, «внезапная смерть» |
| Меньше авиации | цена ФАБ/КАБ, шанс перехвата ПВО по классу «авиация» |
| Сильнее пехота | урон/цена юнитов, доход с точек захвата, лимит юнитов |
| Реже тупики | цена ремонта, «внезапная смерть» |
| Сильнее отстающие | «Компенсация потерь», множители за урон лидеру |
